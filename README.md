# Webcam Zoom

Zoom in and out of your webcam. One file, nothing to install.

## How to use

1. Download `Webcam Zoom.html` (green **Code** button → **Download ZIP**, then unzip).
2. Double-click the file. It opens in Chrome or Edge.
3. Click **Allow** when it asks for the camera.

## Controls

| Action | How |
|---|---|
| Zoom | Mouse wheel, the slider, or `+` / `-` |
| Move around | Drag the picture |
| Quick zoom | Double-click |
| Reset | `0` |
| Mirror | `M` |
| Fullscreen | `F` |

The picture stays on your own computer. Nothing is uploaded or recorded.

It only zooms inside its own window — it does not change your camera in Discord, Zoom or other apps.
